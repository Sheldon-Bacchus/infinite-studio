# Canvas Agent 运行与 E2E 验收

用户已明确授权启动服务、浏览器验证、截图与 E2E，由 AGY MCP 执行，主模型准备验收标准并审阅证据。本次授权替代本任务此前“不运行测试/浏览器”的限制；没有授权移植另一仓库。

## 范围与环境

- 仅本仓库 canvas-agent、studio/web 连接相关源码及专项 E2E；workspace-service/main.go 由其他对话拥有，仅按现有入口启动，不修改。
- 保留当前监听的 43871/17372 及所有用户浏览器窗口/标签页，不重启或关闭这些进程。
- 使用空闲默认端口：Vite 43863、Canvas Agent 17371、必要时本地工作区服务 8086；启动前核对占用，未知进程不得终止。
- Agent 使用独立 CANVAS_AGENT_CONFIG_DIR，测试工作区与作品目录仅写入本轮 artifacts 下的新空目录；不使用或初始化用户真实 infinite-studio-data/agv-works。
- 使用隔离浏览器 context/用户目录和独立测试页面。验证完保留可供用户查看的服务和测试页面，记录自建进程 PID/入口/地址；不得关闭用户页面。
- 不更改正常桌面 49601 路由、DeepSeek 路由或共享 MCP。AGY 失败报告，不换 provider。

## 验收分层

1. 启动与真实页面：Agent health 的源码 entry/版本、网页响应及浏览器渲染、SSE hello、画布真实上报回执。空白页、浏览器控制台或服务失败必须记录原因，不能以 HTTP 200 代替 UI 可用。
2. 真正 UI E2E：通过连接面板绑定/普通接管/unknown 确认强制接管，真实网页执行写操作并验证节点变化；测试项目甲/乙与独立浏览器页面隔离，保留刷新恢复证据。截图覆盖已同步、绑定、被接管、unknown 警告及确认弹窗；敏感 token 不出现在截图、报告或普通日志中。
3. MCP 共享进程：在同一个真实 stdio MCP 子进程中，两个逻辑调用者独立调用 status 获取 A/B token，再分别传入每次工具调用。证明同一进程不同凭据隔离；缺少/错误/旧 token 读写拒绝。此类探针不等于“已验证 Codex 桌面跨聊天复用策略”，须分开报告。
4. 执行与租约：甲被 A 占用时普通绑定 B 失败；B 接管后 A 读写和旧待确认请求拒绝；乙不受影响；同通道重绑取消旧 revision；executing 期间拒接管；现有超时/SSE 断开进入 unknown，普通接管失败，UI 明确确认后 force 成功；并发一条完成不能释放另一条租约；切画布/切回或断线/重连不复活旧授权；晚到结果拒绝。
5. 同步与诊断：回执 clientId/projectId/revision 任一缺失或不一致不得显示成功；同连接旧回执及旧连接回执不得恢复成功；鉴权失败、服务可达但 SSE 未连接等状态准确。
6. 历史：真实 app-server 可得时验证分页首尾、归属和完整性。必须明确区分真实历史运行与模拟协议页的自动化测试，模拟中间页错误/重复游标不能冒充真实分页验收。

## 测试与修复边界

使用成熟 Playwright 与现有 MCP SDK，不手写浏览器协议。可新增专项 E2E 文件与合成夹具，优先复用现有依赖或捆绑运行时，不做无关依赖升级。选择器基于真实页面/源码，不绕过 UI 核心动作只改 store 来冒充点击流程；允许合成项目或故障注入，但须逐项标注。

E2E 控制器的等待和故障注入参数属于测试夹具，不修改产品的超时、重试、大小或并发边界。发现确定的连接缺陷可以最小补修 owned 文件后重跑相关测试；遇到范围外启动阻塞，记录具体错误和最小方案供主模型决定，不顺手修作品/视频模块。

## 输出

专项 tests、结构化 results.json（每项 PASS/FAIL/BLOCKED、证据路径与真实/合成层级）、命令与退出码、已启动进程清单、截图绝对路径、浏览器控制台/服务错误摘要。截图必须来自实际运行页面，不能绘制占位图。AGY 不写 CHANGELOG/pending-test/HANDOFF，主模型审阅后维护。不要泄露全局 token、channelToken、内部密钥或用户历史内容。
