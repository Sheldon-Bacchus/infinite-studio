# 无限片场本地作品仓库立项方案

## 定位与范围

无限片场独立项目；作品库为入口，复用无限虾既有流程。新手走无限虾/虾集/虾塘，老手使用片场内部画布；两者共用作品数据，画布内容反向归档。另一无限画布项目及 MCP 连接、AGV 组件不在本立项实施范围。本任务使用官方 Spec Kit 流程执行。

本轮仅形成方案，未实施、迁移或验收。采用 brainstorming、product-strategy-session、before-you-build 的方向比较、用户任务与首版风险收敛方法。

## 已核实基线

- plugins/canvas/infinite-xia/src/storage.ts 与 workspace.ts：插件直接将 workspace-v1 的 assets 写入浏览器 IndexedDB。
- studio/web/src/stores/use-asset-store.ts：宿主素材通过本地资产 API 保存，与插件入口分离；宿主媒体类型缺 audio。
- workspace-service/internal/workspace/store.go、records.go、files.go：业务 JSON 保存 SQLite，原件保存 files/<fileId>；已有基准修订 CAS、operationId 幂等与 SHA256 校验，当前上传不按内容哈希全局复用。
- workspace-service/internal/workspace/http.go 与 main.go：已有回环绑定、令牌及 Host/Origin 校验；不能把这些写成全新能力。
- 插件 index.tsx 的 toCanvas 保留作品/素材 ID；当前入口未提供完整画布反向归档。
- preserved/web/src/features/xiaji/local-studio-canvas-binding.ts 的旧规则为作品唯一画布；首期沿用，不扩展多画布。
- 实际发现 E:/all-agent-workspace/codex-projects/agv-works，含故事项目与打斗素材候选文档。仅查看目录和文件列表，未读取浏览器数据库，也未核实全部用户数据。

## 根目录与结构

以发现的 agv-works 作为拟定数据根，已有中文目录原样保留。新增 workspaces/<workId>/ 承载规范作品，不自动移动、覆盖原资料。

每作品：work.json（当前提交指针与身份）；commits/<commitId>/（不可变业务快照，含作品、分集、镜头、提示词、资产、画布、生成记录）；media/<sha256>.<ext>（原件）；inbox/（外部媒体待处理）；archive/（归档记录与作品归档位置）；staging/（未提交写入）。根目录 index.sqlite 仅作可重建索引，backups/ 保存迁移备份。

ID 目录固定，不含标题或分集序号；名称和顺序写在清单对应实体。生成输出在记录中引用 media 原件，取消深层 generations/outputs 实体路径。提交保存变更记录并引用未变化的不可变记录，不复制媒体或每次全量历史。

## 数据契约

清单包含 schemaVersion、workId、revision、commitId、operationId、基准修订和引用完整性信息。格式版本与业务修订号独立。未知版本拒绝写入，未来升级先备份。

作品、分集、镜头、资产实体 ID 稳定；内容 revisionId、生成 generationId、媒体 fileId、画布 nodeId 分开。目录名不承担归属推断。素材可被多个镜头/节点引用。

媒体统一 kind=text|image|video|audio。共有 id、名称、来源、创建信息、归属与版本；文件共有 fileId、sha256、bytes、mimeType、相对定位；文本记录 content/编码，图片记录宽高，视频记录宽高/时长，音频记录时长，提取到的声道/采样率可选。未知元数据标未知，不编造。

原件 SHA256 去重范围为同一作品，导入流式校验并复用匹配文件；同字节不同用途仍可保留不同业务资产。各作品自包含，跨作品物理去重后期再考虑。

## 写入协议与 Windows

本地服务是唯一写入者。使用成熟库的排他锁，由进程持续持有，锁文件存在本身不代表有效锁；第二服务拒绝取得同一数据根的写权限。程序内作品级串行提交，多个客户端使用 baseRevision 防覆盖。

提交：检查身份与基准修订；写同卷 staging 原件/记录并同步；哈希与引用校验；发布到全新不可变 commit 目录；以 Windows 支持的文件替换原语切换 work.json 指针；回读确认后返回回执；最后更新可重建索引。禁止用覆盖非空目录 rename 假装多文件原子事务。清单切换前失败旧版本仍权威；切换后索引失败按已提交处理，可重建。operationId 回执随提交记录落盘，重复同内容返回同结果，同 ID 不同内容拒绝。

ID 使用统一小写安全 ASCII，禁止路径分隔符、冒号、点路径、设备保留名、尾随空格/点。上传原名仅作元数据，扩展名由确认的媒体类型映射。按大小写不敏感比较身份。所有外部路径按 ID 解析并校验根目录边界，拒绝绝对路径、..、链接/重解析点逃逸。

采用短浅路径，不依赖启用长路径。传统 MAX_PATH 为 260，但开启长路径有环境条件；不能一概声称 Windows 只能 260。实施前给出最终完整路径预算和兼容性预检，任何新增业务大小/并发/超时限制先说明并取得确认。目标已存在时只允许验证后幂等复用或返回冲突。占用导致替换失败返回保存失败，保留旧版本和暂存数据；不无限重试、不报保存成功。原子可见性不等于所有断电环境下绝对持久，需故障恢复验证。

## 迁移

迁移范围待只读清点：各浏览器/来源的无限虾 assets、宿主素材和画布、可恢复媒体，以及现有 agv-works 文档。服务不能直接读取其他浏览器 IndexedDB，必须从原来源页面显式导出。blob URL 本身不算备份。

先导出 JSON、媒体原件、来源信息、哈希清单和恢复包；只读原数据。建立 sourceId+旧实体ID+版本/内容摘要映射，保留稳定逻辑身份，必要时映射安全磁盘ID。不同来源重复或冲突展示预览，不按名称合并。缺媒体明确登记和阻止宣称完整迁移。

在隔离 staging 生成作品并校验关系、原件、回读；整作品提交成功后才切换读取入口，旧库与备份保留。同一迁移重复执行不新增实体/生成记录。提交前失败可丢弃目标继续旧入口；切换后若新仓库已有新编辑，回退先备份新变更并明确显示，不能无损回退假承诺。未归属素材保存待归档，不强行创建虚构作品。

## 模块接通与双向归档

无限虾业务仓库改接统一本地作品 repository，插件与页面复用服务，浏览器仅缓存/草稿。虾集维护分集、剧本、镜头；虾塘维护领域资产与版本。画布持有对象/内容版本引用和布局。

投放沿用稳定归属、幂等更新。画布新导入或生成的内容自动登记待归档，已知归属记录到正确镜头的尝试列表，未知内容留待归档；手动批量分类及选择结果。自动登记不代表自动选用或直接覆盖剧本。重复回存凭来源身份与内容摘要幂等；复制节点不复制原件，删除节点不删除档案。

生成记录保留实际提示词、输入媒体版本、模型渠道和参数、任务编号、状态与输出 fileId；镜头修订、提示词修订和生成尝试分开，选用结果独立。外部导入没有生成参数时保留未知来源，不补造。

## 归档、外部媒体、导入导出、安全

业务删除统一归档：实体退出当前清单并保存 archive 记录，可恢复；被其他对象或历史引用的原件保留。共享原件不因单实体归档而移动。整作品归档位于根 archive；服务内所有提交/生成回写停止后才移动，占用失败保持原状态。首期无永久清理。

首期不支持文件夹直接改剧本/清单。只在启动或手动扫描发现外部媒体新增/替换，显示差异并由用户采用。导入 inbox 媒体并复制为哈希原件；替换视为新版本。规范 media 不可变，外部同名替换需恢复旧版本或报告缺损，不能假称旧原件仍保存。不做实时监听与自动合并。

作品 ZIP 包含版本化清单、业务记录、历史、归档及引用原件，排除缓存、令牌和未提交 staging。导出固定已提交修订；导入先预览，拒绝路径穿越、大小写冲突、未知版本和哈希失败，在隔离目录验证后提交。同作品导入不得直接覆盖：选择还原到隔离位置或建立副本。现有 ZIP v3 能力需适配作品格式，不视为已有作品 ZIP 验收。

复用 127.0.0.1、令牌、Host/Origin 校验；令牌不存作品或 ZIP。可信页面经既有本地启动/代理链使用凭证，插件复用受限宿主能力，不开放任意文件访问。安全设计不承诺抵御同机恶意程序。

## 顺序与验收

1. 存储契约：版本、Windows、提交/锁/CAS/幂等、身份和媒体模型。
2. 旧数据清点备份与迁移：先完成迁移恢复包，重复执行、失败保持旧数据、原件回读。
3. 无限虾/虾集/虾塘统一入口：同对象跨模块读写一致、刷新重启一致。
4. 画布回存：已知/未知归属、重复回存、复制/删除节点、批量归档。
5. 生成历史：输入快照、结果归属、修订、失败和选用关系。
6. 作品 ZIP、归档恢复、索引重建与故障恢复。

关键验收：两个标签页基准冲突拒绝；第二服务拒绝写入；写入各阶段中断仍有可识别权威提交；媒体哈希复用；迁移重复不重建；缺件明确；ZIP 导入后关系与哈希一致；两种创作入口归档到同一作品。具体执行测试遵循用户届时授权，当前不运行构建/测试。

后期：中文可读视图、实时监听、文本自动合并、复制目录重复ID扫描、多画布、跨作品物理去重。当前需补充实际浏览器/旧数据清单与上述根目录作为正式写入目标的确认；不阻碍方案定稿，不在本轮触碰数据。
