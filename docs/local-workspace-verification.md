# 固定本地工作区验收记录

## 当前状态

实现代码包含已提交初版和后续修复。构建、类型检查、测试、服务启动和浏览器验收均为 **NOT RUN**；静态代码审阅不代表功能通过。

固定数据根当前缺少 `workspace.json`，新服务按设计不会自动登记或初始化现有数据库。本轮未启动服务、迁移数据或运行备份/恢复命令。

## 验收清单

| 场景 | 状态 | 验收要点 |
| --- | --- | --- |
| Edge、Chrome、Codex 内置浏览器共享工作区 | NOT RUN | 相同 `workspaceId`、`canvasId`、节点、连线、素材和媒体原件。 |
| 提交后刷新与重启 | NOT RUN | canonical 版本及记录不变；页面读回最新内容。 |
| 并发修改 | NOT RUN | 同一 `baseRevision` 仅一个提交成功；冲突保留本地草稿，不静默覆盖。 |
| 离线、保存失败与缺失原件 | NOT RUN | 不回退为空浏览器库；画布节点保留并显示失败或缺失状态。 |
| 图片、音频、视频和嵌套媒体 | NOT RUN | 刷新后通过稳定 `fileId` 读取；持久化记录不包含 `blob:` URL。 |
| ZIP v3 导入及中途失败恢复 | NOT RUN | 预览冲突/缺件；重复导入幂等；部分成功后重选可继续。 |
| Agent/MCP 持久回执与重放 | NOT RUN | 保存成功后才确认；按工作区、画布及 `operationId` 核对回执。 |
| 备份、校验及隔离恢复 | NOT RUN | 数据库、manifest 和媒体哈希全通过；只恢复到新目录，身份保持一致。 |
| 未保存离开提示 | NOT RUN | 任意页面有画布或素材未保存时刷新/关闭触发浏览器确认。 |

## 运行边界

- 不以本记录或计划中的实现描述替代运行证据。
- 使用真实数据前，先核对目标目录、备份及冲突清单；恢复始终写入独立的新目录。
- 用户已打开的浏览器和标签页保持原样；浏览器验收使用隔离测试配置。
