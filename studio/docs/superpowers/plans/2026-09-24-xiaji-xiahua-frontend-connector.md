# 虾塘完整前端移植与虾画连接器计划

范围说明：本计划仍记录虾塘页面和基础素材连接器的既有未完成项。虾镜整集/Beat 上下文投影、用户确认后的布局和连线见[2026-09-25 独立计划](2026-09-25-xiaji-beat-context-canvas-import.md)；本文不代表该扩展已完成。当前工作不含虾面、回主线或视频生成。

> 状态：目标仍是完整复用/移植 DramaClaw 虾塘四类资产 UI。当前 `/xiaji` 已有本地重建和连接器，但独立代码审阅确认页面没有完整复用真实来源组件，仍有来源布局与字段缺口；不能判定完成。声线点击崩溃已按 RED → GREEN 修复，年龄默认/覆盖映射已有回归测试。完整范围和未验收项见[执行规格](../specs/2026-09-24-xiaji-xiahua-frontend-connector.md)。

## 不变边界

- `/xiaji` 是独立的虾塘全页；虾画使用 Infinite Canvas 原生画布。
- 复用真实 DramaClaw 虾塘 UI 和控件布局，功能行为全部接 Infinite Canvas 本地素材；不再以通用 `LocalAssetWorkbench` 代替。
- `/xiaji`、连接器和选择器不连接 DramaClaw，不需要其 URL/token，不请求其 API/数据库/任务服务。
- 不增加 DramaClaw 后端、数据库、Go route、任务、生成和写回。
- 两个导入入口共用现有前端 connector、Asset store、media storage 与 Canvas save。
- 角色/场景/道具/声线主记录、身份/变体/声线槽位均使用独立 Asset ID；媒体通过 `parentId` + `slot` 关联。删除实体清理子记录并解除媒体关系，媒体文件保留。
- 全页发送和 Canvas 选择器只导入用户勾选的记录/媒体。保存前读取最新 Canvas 状态；保存成功等待现有持久化 Promise，保存失败展示真实错误并保留选择，不用旧快照覆盖并发编辑。
- 不回滚/覆盖/清理其他脏改动，不提交。复制/改编的源文件保留 Elastic-2.0 版权和 SPDX；AGPL/Elastic 组合需留待分发审查。
