## 目的与范围

在 Infinite Canvas 当前运行的浏览器应用中，找出 DramaClaw 虾料、虾塘、虾镜本地移植的真实用户路径问题，并留下可复核的页面、数据持久化和错误状态证据。本轮执行范围只有：

- **虾料**：导入原稿、结构预览、确认并保存本地项目。
- **虾塘**：角色、场景、道具、声线四类本地素材的浏览、编辑和关联操作。
- **虾镜**：项目、分集、剧本、Beat/镜头草稿的创建、保存、重载和页面导航。

**虾面不纳入本轮验收。** 本轮记录形成后，用户进一步决定将虾面页面、路由和入口从当前产品移除；因此旧四模块产品规格中虾面与“回主线”部分已被取代。本文只保留当时 E2E 的历史边界，不代表虾面仍是后续实现范围。

## 约束

- 浏览器只访问当前 Infinite Canvas 本地应用。不得启动、部署或连接 DramaClaw，不请求 DramaClaw host、`/api/v1/drama/*`、项目/任务/生成服务。
- 不调用文本、图像、音频、视频模型，不触发可能计费的生成请求。虾料使用页面已有的原文标题识别/本地预览路径；虾镜手动编辑并保存剧本和 Beat。
- 不请求麦克风权限，不录制用户声音。声线操作先检查槽位、试听控件、文件选择入口和禁用状态；文件上传单独列为待测项，除非有合成测试文件及清晰的数据清理授权。
- 不安装测试依赖、不改产品代码、不提交、不重置或覆盖已有工作区改动。
- 用户已明确授权创建并清理仅带 `E2E-临时` 前缀的本地测试项目。授权只覆盖本轮新建项目及其可证明归属的原稿、分集、剧本、Beat 和项目内虾塘子素材；不覆盖现有项目、无项目归属的全局虾塘素材或任何画布。删除前必须以只读回读确认全部准确 ID、父关系和外部引用；不能证明归属的记录不删除。
- 保留用户当前浏览器标签和未保存内容；用独立标签进行验收，不清除浏览器状态。

## 用户可见成功标准

1. 虾料接受原稿输入，预览出可检查的结构；保存后项目、原稿和分集在列表中可见，刷新后仍可打开。
2. 虾塘四类页签能切换；项目创作流程从 `/xiaji/project/{projectAssetId}/characters` 进入项目内虾塘，新增/编辑角色、身份、场景、变体、道具和声线槽位后刷新回读字段、父子 ID、项目 ID 和媒体槽关系。只看到 toast 或关闭弹窗不算保存通过。全局 `/xiaji` 只做导航/控件 smoke，不在那里写入无项目归属的测试素材。
3. 虾镜通过范围严格命名为“本地分集 → 手写剧本 → 手工 Beat → 合成页状态 E2E”：经项目卡片打开稳定分集 ID，创建/编辑分集、剧本及 Beat，关联同项目虾塘素材；刷新后复读内容和关系。剩余跨项目伪造引用拒绝与重复序号非法写入仍须单独验收。图片/视频/音频生成、合成进度和成片不计入本轮通过。
4. 各操作在缺少项目、原稿、素材、模型配置或目标能力时给出可理解反馈，不产生假成功。
5. 记录控制台错误、可读的浏览器资源请求、每步结果和截图。只有直接观察到的结果才能标为通过；未运行/被阻塞的路径保持待测。

## 测试数据清理判据

- 每次创建都记录 `runId`、Asset ID、类型、`projectAssetId`、父 Asset ID、关联分集/媒体 ID；创建项目时同时记录服务端回读的 project/source/episode IDs。
- 清理前回读本地 Asset 列表，检查目标集合与已记录 ID 完全相等；查找指向目标集合的脚本、Beat、虾塘父子素材及版本引用。只按“名称带前缀”筛选不足以删除。
- 按子记录到根记录顺序清理本轮精确 ID；清理后经 API 回读确认 active records 为零，并从项目列表刷新确认测试项目消失。共享媒体若仍有其他引用不得物理删除。
- `E2E-临时` 根项目卡片能显示、弹窗关闭、toast 成功、HTTP 200 都不是持久化证据；持久化通过必须在页面刷新后从 canonical 本地工作区重新读取并显示。

## 验收结论等级

- **通过**：真实浏览器完成该路径，并观察到保存后的 canonical UI 状态；需要持久化的路径经过刷新后复核。
- **失败**：操作可执行但行为与预期不符，记录复现步骤、实际结果和证据。
- **阻塞**：缺测试数据/授权、缺本地能力、页面不可达或工具无法观察关键状态；不得按通过计。
- **未测**：本轮没有尝试。单元测试、静态检索、页面路由存在都不能替代 E2E 通过。
