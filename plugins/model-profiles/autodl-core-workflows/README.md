# AutoDL 核心视频工作流配置包

本目录提供两份配置文件，请根据你使用的版本选择导入：

1. **公网官方站（[https://canvas.best/](https://canvas.best/)）专用**：`AutoDL-官方上游全局配置(canvas.best).json`
   - 采用官方上游完整全局备份结构（包含 `config`、`webdav`、`promptSources`），不会触发官方站的「无效的配置文件」校验报错。
   - 已将 AutoDL ComfyUI 官方 5 个工作流的任务提交与结果轮询协议直接内嵌到每个模型的自定义调用脚本（`script`）中，利用官方上游自带的模型插件引擎（`runModelPlugin`）即可在 `canvas.best` 直接发起生成。

2. **本地版（`http://127.0.0.1:43863` / `http://127.0.0.1:43871`）专用**：`AutoDL-核心视频工作流.json`
   - 打开「配置 → 导入配置」，选择这个 JSON。导入器会合并 AutoDL 渠道，只保留该渠道的五个预设工作流、保留已有 AutoDL Token 和其他渠道，并把 H3 多图多音频升级画质工作流设为默认视频模型。配置包不含密钥。

此目录属于模型渠道配置包，不是 `plugins/canvas` 下的画布节点插件。已接入 AutoDL 官方 ComfyUI 工作流 API（任务提交与结果轮询协议），此配置包提供五个工作流：H3 多图多音频原版（15秒）、H3 多图多音频升级画质版、H3 对口型同步、H3 首尾帧和 Wan 2.2 动作迁移；升级画质版仍为默认视频模型。H3 多图多音频升级画质支持 1–15 秒、最多 9 张参考图和 3 段参考音频，分辨率为 480p / 768p（横版、竖版、方形）；至少需要一张参考图和提示词。使用前请在渠道中填入 AutoDL ComfyUI 令牌（Token）。素材推荐使用可公网访问的图片/视频/音频 URL。
