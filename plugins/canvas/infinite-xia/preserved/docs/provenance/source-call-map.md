## 映射约定

- `project` 在来源中是 DramaClaw slug；目标改为本地 project Asset 的稳定 ID。来源 slug 永不发送或转换为远端调用。
- 来源 `episode` / `episodeNum` / `beatNum`、查询 `beat` / `focusBeat` 是数字序号，只用于旧链接兼容；目标新分集 URL 走 `/episodes/by-id/[episodeAssetId]`，新镜头 query 使用 `beatAssetId` / `focusBeatAssetId`。旧序号先按 metadata 中保留的来源序号唯一解析，手工本地内容才回退到唯一 `localStudio.order`。
- 来源角色、身份、场景、道具名称/编号映射为本地稳定 Asset ID；领域字段保存在 `metadata.localStudio`，媒体通过 Infinite Canvas 现有 file service 上传并保存其本地引用。
- 下文所写 `LocalStudioRepository.*` 是**拟议适配器边界**，不是当前已存在的实现。现有底层是 Infinite Canvas 本地 Asset store、`/api/local/assets/sync`、文件上传和 Canvas 保存能力；阶段 1 才会核定具体 TS 签名。
- Query cache invalidation 不是业务动作。表中说明来源副作用应改成目标 canonical Asset 更新、关系索引重算或列表刷新；没有本地能力的请求/控件要移除远端 handler 并禁用或显示明确原因。
