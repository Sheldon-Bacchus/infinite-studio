# 无限画布素材组对话纪要

> 本文根据素材组源码补丁说明、整合后的画布源码及仓库内历史验证记录整理，属于内容摘要，不是逐字聊天导出。公开仓库不收录用户的画布数据库、媒体、素材包或私人创作内容。

## 功能目标

让一组素材可以作为一个输入接入生成配置，避免为每个组成员重复连线，同时继续保留素材节点之间的独立编辑和画布布局。

## 当前实现与约束

- 选中至少两个未分组的普通节点后可用 `Ctrl+G` 建组；也可将新节点拖入已有组。
- 组框提供组合输出。将组连接到生成配置后，配置会展开组内有内容的文本、图片、视频和音频节点。
- 组连接只允许从组到生成配置。空节点、配置节点和导演台不作为组素材传入；素材重复时按节点去重。
- 分组是平级的；创建新组时不能把已有组或已属于其他组的节点再次收进组。
- 组连接和素材展开代码位于[无限画布项目](../../)。项目包含连接校验和资源展开实现；本机旧补丁包不是插件，也不是“导入画布”可读的项目包，无须单独安装。
