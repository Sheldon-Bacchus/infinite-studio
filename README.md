# Infinite Studio + Infinite Canvas

本仓库只包含两个项目：无限片场和无限画布。MCP 与插件分别放在所属项目目录内，不单独作为第三个项目。

| 项目 | 内容 |
| --- | --- |
| [无限片场 `studio/`](studio/README.md) | 无限虾工作流、Studio API 与前端；Studio 的 Canvas Agent 插件位于 `studio/canvas-agent/`。 |
| [无限画布 `canvas/`](canvas/README.md) | Infinite Canvas 完整源码、文档、素材组与存储实现；社区 MCP 位于 `canvas/mcp/`。 |

来源提交、许可证和资料分类见[项目清单](IMPLEMENTATIONS.md)。各项目的依赖安装、启动和数据目录以各自 README 与文档为准。
