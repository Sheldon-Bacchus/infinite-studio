# Feature Specification：画布连接组件完善

**Status**：用户已采纳当前仓库实施方案；真实桌面身份、部分浏览器故障、完整历史和跨仓库移植仍待验收/另行授权。**Feature**：002-canvas-connection；尚未创建 Git 分支。

**Input**：延续 SDD / Spec Kit，完善 Canvas Agent 连接组件；当前仅在无限片场仓库实施。向独立 Infinite Canvas 仓库移植需要单独确定工作范围。

## User Scenarios & Testing

### US1 恢复连接并理解状态（P1）

用户在连接面板看到真实运行地址、网页连接和画布同步结果，可以重新连接当前页面。

独立验收：Agent 运行但无网页时显示“服务可用，网页未连接”；网页连接但无画布时显示“请选择画布”；状态同步成功后显示画布名称。

1. Given 服务未运行，When 连接，Then 显示实际地址和服务不可访问，保留表单。
2. Given Token 无效，When 连接，Then 显示鉴权失败，不误报 MCP 缺失。
3. Given 画布快照上报失败，Then 不显示“画布已同步”。

### US2 明确目标与接管（P1）

用户明确选择目标聊天与画布，绑定后切换焦点不改变目标。接管使旧授权失效，并保留聊天和标签。

独立验收：A 绑定画布甲，B 接管后 A 读取与写入均被拒绝；甲上的旧待确认请求不能执行；乙不受影响。

1. Given 目标已被占用，When 普通绑定，Then 返回占用状态。
2. Given 请求尚未执行，When 接管，Then 取消旧请求并拒绝晚到结果。
3. Given 操作已经开始，When 接管，Then 显示“操作执行中”，完成后可重试，不中途改投目标。
4. Given 同一 MCP 进程被多个聊天复用，Then 不得声称聊天隔离成立；身份来源缺失时拒绝启用聊天级绑定。
5. Given 网页切换画布，Then 原画布授权失效，需要明确重新绑定。

### US3 恢复侧栏历史（P2）

分页线程读取全部历史，不因 API 不支持 includeTurns 进入失败状态。

独立验收：多页历史首尾消息和归属一致；中间页失败明确报错，不把部分结果宣称完整。

### US4 稳定启动与诊断（P2）

快捷启动、插件和网页提示使用同一本地 Agent；显示版本、源码来源和端口；后台服务重启后可重新连接。

## Requirements

- FR01：区分服务可达、网页 SSE、画布同步、MCP 可用、聊天历史状态。
- FR02：表单、重连、目标选择、绑定、接管与错误提示复用现有 AgentConnectView、API 服务和 Zustand store。
- FR03：聊天身份必须来自可信调用上下文或显式独占会话通道；随机 MCP sessionId 只代表连接。
- FR04：授权固定调用者、网页 clientId、projectId 和 revision；每次工具调用校验，禁止隐式焦点回退。
- FR05：待执行请求失效；已开始执行的操作有明确完成边界。已执行副作用不承诺撤销。
- FR06：不增加未经确认的超时、重试、并发和大小边界。
- FR07：不删除历史、不关闭标签、不修改资产模块或进度组件。
- FR08：错误按证据分类；无法区分网络与浏览器拦截时如实显示。
- FR09：保持主题和扁平中文 UI，普通用户无需理解内部协议字段。
- FR10：运行状态恢复不等于验收；原型、审阅、运行证据、待验收分开登记。

## Success Criteria

- SC01：各连接阶段与服务实际状态一致，错误可定位至失败环节。
- SC02：A/B 聊天及甲/乙画布交叉场景无越权写入；共享进程情形也必须覆盖。
- SC03：接管前后历史和标签保留，旧待确认请求不能执行。
- SC04：完整分页历史恢复，错误不得伪报完整。
- SC05：片场实验与画布移植使用相同契约，启动入口和真实进程一致。

## 当前证据

片场隔离服务曾运行于 Web 43863 / Agent 17371；用户原有 Web 43871 / Agent 17372 未关闭。Agent 构建通过，session 定向测试 29 项通过；目前 17371 仍报告协议 7，而源码协议已升至 8，因此旧服务截图不能作为协议 8 验收。故障结果 FAULT-001–007、009 留有旧服务证据；主模型复核截图后将 FAULT-008 确认弹窗和 FAULT-010 甲乙隔离降为 BLOCKED，AGY 已修正两项控制器断言但尚未运行。整站 typecheck 多次因 AGY 执行环境内存不足未执行；workspace-service 全量 Go 测试被未归本任务的 `internal/works` 编译错误阻断。T001 原始断连原因、T004 桌面跨聊天身份、T008 完整 E2E、T009 真实 app-server 分页、T010 第二启动路径及 T011 移植仍未完成。用户已采纳修订方案并授权 AGY 执行本仓库编译与浏览器验收；后续运行需等待 AGY 环境可用内存稳定超过 2.5 GB。


## SDD 扩展：生成任务队列与日志（最终设计，待实现）

本扩展按用户要求继续维护现有 spec，不新增 Feature。既有 Agent 连接需求及验收状态保留；原 FR07 不修改视频/进度组件的限制仅适用于原连接专项，本扩展明确新增媒体生成任务组件范围。媒体生成队列与 Agent 工具请求队列分别管理，不互相取消或共用执行状态。本轮授权为方案与文档，不代表启动生成或执行代码。

### 产品决策

采用全局任务中心抽屉、画布节点状态与单任务详情联动。顶栏展示进行中和需处理数量；抽屉提供任务列表及概览、发送内容、日志、结果四个详情页签。节点显示阶段、耗时及查看任务入口。第一版范围为画布视频生成；图片、音频后续复用契约，不声称已接入。完整独立任务页面、批量优先级调度和后台常驻调度不列入首版。

目标：用户无需猜测是否提交、卡在哪、能否恢复、是否会重复计费。观察指标为未知提交重复发送次数、刷新任务恢复成功率、失败阶段可解释率；目标值在验收基线建立后确定。

### US5 看清提交与失败阶段（P1）

点击生成即创建一次可追溯尝试；缺媒体能力声明、未解析引用等检查失败显示“检查未通过·未提交”，给出配置或素材修正入口。检查失败不进入可调度队列。

验收：缺声明时远程生成请求为零；日志明确缺失字段及当前渠道模型身份，不推断接口不支持图片；修正后重新检查并创建新尝试，保留旧失败记录。

### US6 刷新与断线后恢复任务（P1）

刷新后恢复持久化记录；有远程任务 ID 则查询原任务。提交已开始但未取得远程 ID 时为“提交结果待确认”，不能自动重新发送。网络断开不等于远程失败。

验收：刷新不产生第二次提交；查询失败保留远程 ID 和上次确认状态；生成完成、下载失败只重新下载，不重新生成；服务重启不承诺浏览器关闭后自动调度。

### US7 在任务中检查实际输入（P1）

发送内容展示本次不可变快照：渠道/模型完整标识、适配器身份版本、编译后提示词、实际素材及参数。与编辑面板共用候选构建器；调度前再次校验素材可用性，不静默替换素材或重写快照。

验收：提交后修改画布不改变历史；选择参数与实际发送参数不同必须显示差异，无法确认映射时阻止提交；只有一张人物图不生成其他 Subject 或资产。

### US8 任务管理与诊断（P2）

按画布、渠道和状态筛选任务；任务与节点双向定位，节点被删除时仍能打开历史并明确说明。日志默认显示中文阶段与原因，技术详情可展开；导出诊断包先脱敏。

### 功能要求

- QFR01：任务状态、当前阶段、提交受理结果、连接情况、输出保存情况分别保存，不能用单一 failed 覆盖不确定状态。
- QFR02：无真实进度仅展示阶段/耗时；不伪造百分比、计费金额、预计完成时间。
- QFR03：发送前持久化尝试；保存失败则不提交。远程 ID 收到后立即持久化，保存失败显示本地记录风险且不重发。
- QFR04：同节点重复点击复用正在提交的尝试，不新增并发请求；再次生成新建尝试并关联父尝试。
- QFR05：区分本地排队、服务端排队；暂停本地队列不影响远程已受理任务。
- QFR06：取消本地排队、停止查询、取消远程生成是不同动作。远程取消必须渠道明确支持且确认结果；停止查询保留远程任务可恢复。
- QFR07：不自动重试生成提交；查询/下载沿用当前机制。新增重试、超时、并发、大小和日志保留边界须另行确认具体默认值及失败行为，本 spec 不预设数值。
- QFR08：日志记录本地尝试 ID、事件序号、时间、阶段、原因码及可用的远程关联 ID；缺证据时显示未知。
- QFR09：不存 API Key、Authorization、WebDAV 密码、带凭据的 URL。诊断导出默认不包含完整创作正文与媒体原件，用户可明确选择加入。
- QFR10：统一任务 store/调度入口负责状态；列表、节点、历史为同一记录的投影，不各自轮询远程接口。
- QFR11：浏览器关闭期间首版不保证本地队列运行。重开后核对远程任务；多标签页同一尝试只有一个提交执行者，获取不到执行权则只读，不能默认多个页面安全并行。
- QFR12：任务日志与服务日志分开；Workspace/Web/Agent 可达状态显示在任务中心服务诊断区域。EPIPE 等仅在真实日志有证据时归类为服务故障。

### 验收场景补充

QAC01 缺适配器声明：本地 blocked，受理为未发送，生成请求零次。
QAC02 提交响应丢失：结果待确认，禁止自动重发；无远程核对能力时明确人工确认边界。
QAC03 页面刷新：恢复同一任务与远程 ID，查询不造成重新提交。
QAC04 远程完成下载失败：保留完成事实，重新下载成功后只追加保存事件。
QAC05 取消不支持：显示停止查询选项，不声称取消远程或停止计费。
QAC06 提交后编辑：原快照、引用顺序和实际参数不变。
QAC07 双标签页点击：同一尝试最多一次提交；晚到事件不得回退终态。
QAC08 删除节点/切换画布：任务仍可查，定位缺失有明确提示。
QAC09 脱敏导出：测试凭据与签名参数不出现在导出内容。
QAC10 队列等待期间素材改变/丢失：重新检查并阻止发送，不静默改输入。
