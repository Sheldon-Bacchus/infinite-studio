# Feature Specification：画布连接组件完善

**Status**：用户已采纳当前仓库实施方案；真实桌面身份、部分浏览器故障、完整历史和跨仓库移植仍待验收/另行授权。**Feature**：002-canvas-connection；尚未创建 Git 分支。

**Input**：延续 SDD / Spec Kit，完善 Canvas Agent 连接组件；当前仅在无限片场仓库实施。向独立 Infinite Canvas 仓库移植需要单独确定工作范围。

## User Scenarios & Testing

### US1 恢复连接并理解状态（P1）

用户在连接面板看到真实运行地址、网页连接和画布同步结果，可以重新连接当前页面。

独立验收：Agent 运行但无网页时显示“服务可用，网页未连接”；网页连接但无画布时显示“请选择画布”；状态同步成功后显示画布名称。

1. Given 服务未运行，When 连接，Then 显示实际地址和服务不可访问，保留表单。
2. Given Token 无效，When 连接，Then 显示鉴权失败，不误报 MCP 缺失。
3. Given 画布快照上报失败，Then 不显示“画布已同步”。

### US2 明确目标与接管（P1）

用户明确选择目标聊天与画布，绑定后切换焦点不改变目标。接管使旧授权失效，并保留聊天和标签。

独立验收：A 绑定画布甲，B 接管后 A 读取与写入均被拒绝；甲上的旧待确认请求不能执行；乙不受影响。

1. Given 目标已被占用，When 普通绑定，Then 返回占用状态。
2. Given 请求尚未执行，When 接管，Then 取消旧请求并拒绝晚到结果。
3. Given 操作已经开始，When 接管，Then 显示“操作执行中”，完成后可重试，不中途改投目标。
4. Given 同一 MCP 进程被多个聊天复用，Then 不得声称聊天隔离成立；身份来源缺失时拒绝启用聊天级绑定。
5. Given 网页切换画布，Then 原画布授权失效，需要明确重新绑定。

### US3 恢复侧栏历史（P2）

分页线程读取全部历史，不因 API 不支持 includeTurns 进入失败状态。

独立验收：多页历史首尾消息和归属一致；中间页失败明确报错，不把部分结果宣称完整。

### US4 稳定启动与诊断（P2）

快捷启动、插件和网页提示使用同一本地 Agent；显示版本、源码来源和端口；后台服务重启后可重新连接。

## Requirements

- FR01：区分服务可达、网页 SSE、画布同步、MCP 可用、聊天历史状态。
- FR02：表单、重连、目标选择、绑定、接管与错误提示复用现有 AgentConnectView、API 服务和 Zustand store。
- FR03：聊天身份必须来自可信调用上下文或显式独占会话通道；随机 MCP sessionId 只代表连接。
- FR04：授权固定调用者、网页 clientId、projectId 和 revision；每次工具调用校验，禁止隐式焦点回退。
- FR05：待执行请求失效；已开始执行的操作有明确完成边界。已执行副作用不承诺撤销。
- FR06：不增加未经确认的超时、重试、并发和大小边界。
- FR07：不删除历史、不关闭标签、不修改资产模块或进度组件。
- FR08：错误按证据分类；无法区分网络与浏览器拦截时如实显示。
- FR09：保持主题和扁平中文 UI，普通用户无需理解内部协议字段。
- FR10：运行状态恢复不等于验收；原型、审阅、运行证据、待验收分开登记。

## Success Criteria

- SC01：各连接阶段与服务实际状态一致，错误可定位至失败环节。
- SC02：A/B 聊天及甲/乙画布交叉场景无越权写入；共享进程情形也必须覆盖。
- SC03：接管前后历史和标签保留，旧待确认请求不能执行。
- SC04：完整分页历史恢复，错误不得伪报完整。
- SC05：片场实验与画布移植使用相同契约，启动入口和真实进程一致。
