用户明确继续完成 plan/tasks。T003–T010 代码落地及主模型静态审阅完成，已勾选；运行验收独立记 pending-test，不阻断后续代码任务。按 Phase 4→5→6 顺序由 AGY 实现，主模型每批聚焦审阅接口、归属、实际可达入口及提交边界，不运行测试、编译、语法检查、typecheck 或构建。

## Phase 4：T011–T014

旧来源只读，来源包包含业务快照、稳定来源 ID、内容摘要和真实原件。使用现有 fflate/Web Crypto 与 Go archive/zip/sha256/json。预览不发布，缺件/关系冲突阻断提交；确认提交先保存完整来源包及摘要备份，再沿作品基准/操作幂等协议发布。原来源保留可读。前端复用 /api/local 可信代理，不下发令牌；迁移页必须路由可达并提供显式确认与切换。

## Phase 5：T015–T020

- use-works-store 管理当前作品、详情、草稿、提交、冲突和切换；小配置保存当前 ID，业务草稿用 localforage。切换有未提交草稿时显式处理，不静默丢弃；提交回执确认后再替换权威视图。
- 无限虾现有 repository 的 getAssets/saveAssetsAndWait/readCanonicalAssets 接到统一作品 adapter，沿既有业务函数，不重做 UI 或整套 repository。无作品归属时保留旧来源的显式迁移入口；有作品后禁止把服务失败降级为写旧 IndexedDB。
- 插件通过既有公共 runtime 的 works capability 使用宿主 adapter，宿主的实际请求仍统一放 services/api/works.ts；同步宿主 canvas-plugin 类型与 SDK 公共镜像。adapter 提供选中作品、读取/保存 Asset 视图、订阅作品变化和归档能力，插件不导入宿主内部 @/ 路径，不自行复制 HTTP 客户端。未选作品时提示选择/迁移，旧来源只读展示，不自动创建或写回旧来源。
- 序列化复用 Phase 4 来源转换/映射，保持项目/分集/镜头/虾塘的原 ID 与稳定作品实体 ID 对照；原始业务属性通过明确版本化的元数据投影保存，媒体原件用 fileId/哈希定位，业务记录不嵌入 base64。保存后读回同一提交重建插件 Asset 视图。
- 作品页提供列表、新建、选择、迁移入口、冲突及保存状态；作品库导航须可达。沿现有全局主题、中文文案与页面结构。
- 统一 NodeRef：objectId、revisionId、sourceId，节点实例 ID 是 map 键，与作品/对象/修订身份独立；一作品一画布，绑定不同画布拒绝静默覆盖。复制节点不生成重复业务记录。
- 绑定记录保存关联画布的版本化快照（节点、连接、视口及已有画布业务状态），媒体改为作品 fileId/原件引用，打开作品可从权威记录恢复画布；现有画布 store 继续作为界面缓存/旧来源，不让作品恢复依赖旧浏览器。复用既有 CanvasProject 校验/导入函数，不把全局渠道密钥或服务令牌保存进作品。
- 投放节点携带 workId/objectId/revisionId/fileId/原来源 ID；反向批量归档凭这些身份和内容摘要复用/新增修订。新结果不覆盖旧版本、不自动选用；未知归属进入待归档资产集合。
- 画布生成完成仅局部挂入归档登记，不改视频候选/Subject 绑定逻辑，不修改另一对话拥有的连接组件/Agent store。异步登记捕获启动时作品与生成身份，切换作品后仍归原作品，失败保留可重试状态。
- 宿主音频扩展复用既有 audio 节点与文件存储，仅补 Asset 联合类型/API守卫及实际使用所需分支；保持已有图片/视频行为。

## Phase 6：T021–T025

- 镜头稳定 ID 与内容/提示词修订分离，沿旧版本链确定归属；生成保存实际输入快照、渠道/模型参数、远程任务 ID、结果/失败及选用关系。重试是新尝试，回存同尝试幂等，外部输入缺参数保持未知。
- 归档/恢复使用原有 baseRevision/operationId 提交，实体和历史原件保留，不做永久删除。
- 作品 ZIP 固定已提交 revision，包含清单、提交链、不可变记录、所有引用原件及归档/来源关系；排除令牌、索引、缓存和 staging。用标准 ZIP 实现拒绝穿越、大小写重复、链接、未知 schema 和摘要错误；导入先预览再隔离发布，不覆盖现有同 ID 作品。
- 恢复核对当前权威 head 与不可变链，只报告/处理已确认未提交残留，不推断孤立提交已生效，不覆盖未知/损坏清单。inbox 仅手动扫描与显式采用为新媒体版本，不实时监听或自动合并剧本。
- 不新增未经确认的大小/超时/并发/重试阈值，不自动迁移真实作品目录。
